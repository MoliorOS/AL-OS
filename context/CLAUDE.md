# context/ — the tacit-knowledge layer

Not documentation. Each file here extracts a specific piece of knowledge that today exists only
in a person's head, or migrates knowledge that already exists in writing (`docs/source-corpus/`,
the audit) into a usable form.

**Every file names an owner and states whether it's migrated or extracted.** Migrated files are
close to complete. Extracted files — `scope.md`, `technical.md`, `finance.md`, and parts of
`commercial.md`, `delivery.md`, `governance.md` — are honestly incomplete until the named person
sits down and fills the `## Open — not yet captured` section.

**Never write a placeholder.** If you don't know something, say so specifically, in the open
section, with who can answer it. A reader should never see a bracketed `[TBD]`.

See `AGENTS.md`'s routing table for which file owns which fact.
