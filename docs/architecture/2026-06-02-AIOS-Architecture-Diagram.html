Two cores sit between AL's tools and its people. The OS (operational core) holds the firm's workflows as skills — each skill loads its own static context, queries the Brain for live context, and acts on the tools. The Brain (knowledge core) is an intelligent relational data layer on Supabase — three schemas custom to AL's IP, kept current by scheduled ETL and made smart by a dream cycle that enriches, consolidates and derives insight from every action. The governing rule the diagram encodes: reads come from the Brain; actions go to the Tools. Only two arrows touch the tools — sync in, act out. Everything the team sees and triggers flows through the OS ⇄ Brain heartbeat in the middle. The Dashboard (Metabase) is an optional surface on top of the Brain's schemas; the system is fully operable through an AI session alone.
