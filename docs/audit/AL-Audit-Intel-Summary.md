### Biyi's ArchiCAD CLI (Current Build)

**Architecture:** Started as MCP server (Taper plugin bridge for Rhino/Grasshopper → ArchiCAD). Optimized to HTTP connector (localhost port, like port 3000). No data leaves the office — runs on individual desktop machines.

**Live Use Cases Already Built:**
1. **Apartment auto-layout:** Fill furniture + internal layouts from external footprint + zone sketches; scalable to 20–30 apartments
2. **Compliance checking:** Auto-check stairs/elevators against building regs; auto-update non-compliant elements
