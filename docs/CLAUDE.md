architecture thinking, AL's own policy corpus, and the client-supplied source material.

**Rule: read these, don't edit them in place.** If something here is superseded, write a new
entry in `docs/decisions/` rather than rewriting the original — the original is a historical
record of what was found or agreed at the time.
